# Countries_Dashboard
Country dashboard to display information about countries and manage a wishlist

WARNING: This project can no longer be used as the API version used for this project is no longer in use and the new API version does not have enough data for what the application needs. A new version similar to this project is being made using similar technologies and working with a restAPI. This can be seen on the Games Dashboard repository. You may still look at the code.

This is a project from my object oriented programming module designed using Java and open source REST api (https://restcountries.com/) that displays information about different countries. In this application you can manage a simple wishlist, play a quick quiz game based on the information displayed and view different countries around the world. The main purpose of this project was to apply object oriented programming concepts, integrate a GUI framework with Java and interact with a REST api to retrieve meaningful information. 

# TECHNOLOGIES
Java Swing, Java, Intellij

# LESSONS LEARNED
This project helped me apply different programming concepts and see how they can be useful when developing an application. For example using polymorphism helped with structuring my graphs and menus for more flexibility and helped reduce repeated code. I also learned how to work with RESTAPI's for the first time and saw how I could make my own API in the future.
